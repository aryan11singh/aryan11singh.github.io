## 🚀 How to Deploy to GitHub Pages

1. **Create Repository on GitHub**:
   - Go to [GitHub New Repository](https://github.com/new).
   - Set Repository Name to: `aryan11singh.github.io` (Must match your GitHub username!).
   - Set visibility to **Public**.

2. **Push files to GitHub**:
   ```bash
   cd D:\Project\aryan11singh.github.io
   git init
   git add .
   git commit -m "feat: initial commit for aryan11singh.github.io portfolio"
   git branch -M main
   git remote add origin https://github.com/aryan11singh/aryan11singh.github.io.git
   git push -u origin main
   ```

3. **Verify GitHub Pages is Live**:
   - Go to your repository on GitHub -> **Settings** -> **Pages**.
   - Under **Build and deployment**:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main` / `/(root)`
   - Within 1–2 minutes, your website will be live at:
     👉 **`https://aryan11singh.github.io`**
